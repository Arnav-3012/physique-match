# learn/ — written with /sensei at the end of each major phase (P3, P4, P5, P6; P2 on request)

Each phase gets `learn/phase-NN/` with exactly these files, written beginner -> advanced ("0 to 100"):

| File | Contents |
|---|---|
| `concepts.md` | Every new concept used this phase. For each: intuition (analogy) -> how it works -> the math -> how it shows up in *our* code (file:function) -> common mistakes -> 3 self-quiz questions with answers. |
| `model-architecture.md` | Every model touched this phase (MediaPipe, ResNet-18 Siamese, bge-small, LLM): diagram, layer-by-layer shapes, params, why chosen, what breaks it. Skip if no model this phase. |
| `phase-overview.md` | What was built, data flow diagram, decisions + why, metrics achieved vs gate, what went wrong, what to explain in an interview (5 Q&As). |

Rules: link to real files in the repo, use our real numbers from `docs/logs/dev-log.md`, no generic textbook filler.
