# Example week: 3 full-body days (gym)

This is an example layout, not a prescription. The set counts are this app's own design. Only two numbers behind it come from research: about 4 weekly fractional sets per muscle group as a typical minimum, and about 11 fractional sets per muscle group in one session as a soft upper guide (see the volume document). Because the evidence finds a small effect of training frequency on muscle size, a three-day full-body week is one of several layouts that can reach the same weekly volume.

It needs a barbell, dumbbells, a cable station and a few machines.

**Day 1:** bench press 3 sets, bent-over barbell row 3, squat 3, side lateral raise 2, dumbbell biceps curl 2, crunches 3, thigh abductor machine 2.

**Day 2:** pull-ups 3, standing dumbbell press 3, lying leg curl 3, glute bridge 3, triceps pushdown 3, standing calf raise 3, thigh adductor machine 2, dumbbell shrug 2.

**Day 3:** bench press 3, bent-over barbell row 3, squat 3, dumbbell biceps curl 2, crunches 3, dumbbell wrist curl 3, thigh abductor 2, thigh adductor 2, dumbbell shrug 2.

Counting a set as 1 for each main muscle and 0.5 for each helping muscle in the exercise library, every tracked muscle group reaches at least 4 weekly sets and none goes past 11 in one session. A test checks this against the library, so a change to the layout that drops a group below its minimum fails loudly.
